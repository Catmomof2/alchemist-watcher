# The Alchemist's Watcher

**The Alchemist's Watcher** is an automated, real-time EPUB rendering tool designed for markdown purists. It monitors a Markdown file for changes and automatically converts it into a professionally formatted EPUB document using Pandoc and custom gothic-style CSS.

## Features
- **Real-time Monitoring:** Automatically triggers conversion upon saving your Markdown file.
- **Gothic Styling:** Includes custom CSS for drop caps, elegant typography, and a classic manuscript feel.
- **Pandoc Integration:** Leverages the power of Pandoc for high-quality EPUB generation.

## Project Structure
- `watcher.py`: The Python script that monitors the Markdown file.
- `gothic.css`: Custom styling for the generated EPUB.
- `manuscript.md`: Your source Markdown file.
- `output/`: Directory where the generated EPUB files are saved.

## Setup and Usage
1. **Install Dependencies:**
   - Python 3.x
   - `watchdog` library: `pip install watchdog`
   - [Pandoc](https://pandoc.org/installing.html)

2. **Run the Watcher:**
   ```bash
   python3 watcher.py
   ```

3. **Write and Save:**
   Edit `manuscript.md` in your favorite editor. Every time you save, the EPUB in the `output/` directory will be updated instantly.

## Customization
You can modify `gothic.css` to change the look and feel of your EPUB, or update `watcher.py` to point to different source files or output directories.
